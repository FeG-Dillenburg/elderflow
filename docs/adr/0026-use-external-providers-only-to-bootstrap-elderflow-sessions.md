# Use External login providers only to bootstrap ElderFlow sessions

External authentication validates an existing User and then issues the same ElderFlow session as Local login; provider access, ID, and refresh tokens are neither retained nor used after the callback, and ElderFlow requests no offline access. Disabling or removing the provider affects only future logins and does not revoke already-issued ElderFlow sessions, which retain their ordinary maximum 12-hour lifetime. ElderFlow logout locks Protected text and ends only the ElderFlow session rather than initiating provider-wide logout, avoiding authentication-origin tracking and long-lived third-party credentials at the cost of leaving both the provider's browser session and already-issued ElderFlow sessions to expire under their existing rules.
