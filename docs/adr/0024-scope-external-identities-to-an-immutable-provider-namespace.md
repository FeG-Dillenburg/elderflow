# Scope External identities to an immutable provider namespace

External identities are scoped to the immutable provider namespace that issued them. Provider type, OpenID Connect issuer, ChurchTools installation URL, and client ID are therefore identity-defining and cannot be changed in place after the provider has been configured; an administrator who wants to switch any of them removes the existing provider and configures a new one rather than using a staged replacement workflow. Changing the Public ElderFlow URL or replacing or removing a client secret preserves identity links but invalidates the successful test until the changed connection completes another real login test; changing only the display label, enabling, or disabling an otherwise unchanged provider preserves both links and test approval. Removing a provider deletes its usable configuration and encrypted credentials and hides its login button, but retains the inactive namespace and historical identity links; configuring a provider again creates a new namespace, requires a new test, and links Users again by email without changing Local login credentials or already-issued ElderFlow sessions.
