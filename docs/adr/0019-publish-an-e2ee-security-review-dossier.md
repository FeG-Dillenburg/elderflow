# Publish an E2EE security review dossier

The encrypted collaboration effort must produce an E2EE security review dossier containing the threat model, Protected-text inventory, cryptographic protocol and key lifecycle, collaboration data flow, dependency rationale, test vectors, running-instance verification steps, and known limitations. ElderFlow will reserve the term security audit for an assessment performed by an independent reviewer and will not treat the project-authored dossier as proof of an external audit.
